# 数据约定

原始 Excel、候选人名单、清洗面板、逐岗位预测和本地绝对路径不进入 Git。需要使用者自行取得合法可用的数据并配置路径。
`config.example.json` 给出项目内相对路径示例。复制为被 Git 忽略的 `config.local.json` 后修改。

## 输入

| 输入 | 年度 | 必需字段 |
| --- | --- | --- |
| 岗位表 | 2019—2025 | 部门代码、部门名称、用人司局、招考职位、职位代码、考试类别、职位属性、机构层级、招考人数、专业、学历、学位、政治面貌、基层工作最低年限、服务基层项目工作经历、面试人员比例、工作地点、备注等 |
| 历年分数表 | 2019—2025 | 招录机关、部门代码、用人司局、招考职位、职位代码、最低面试分数 |
| 预测岗位表 | 2026、2027 | 与历史岗位表相同口径 |
| 独立检验名单 | 2026 | 仅导入岗位字段及最低面试分数，不读取姓名、准考证号 |

历史分数表应提供仅含岗位信息的版本。若文件含个人信息，不应提交到仓库。
岗位表首行可能是说明，字段在下一行；2027 工作簿还含空白页。当前代码按已研究的格式处理，遇到新格式先审计。

## 唯一键与分数

年度、六位部门代码、十二位职位代码共同构成唯一键。岗位代码不能默认在跨年稳定。
人员名单中的岗位最低线可能重复出现；先检查同岗位分数及名称是否一致，再合并成每岗位一条。
缺少进面分的岗位不填零；调剂、补录和取消岗位不自动推断。
普通、公安、金融监管、证监与非通用语岗位保留原始分数口径，评估必须分组报告。

## 年度核验

文件名不能单独证明年度。此前三个标为 2026 年的学历筛选表，20,245 个去重岗位的核心字段全部与 2025 表一致，已被排除。
真实目标岗位表使用北京体育大学转载的招考简章附件，来源页面：
https://jy.bsu.edu.cn/front/showContent.jspa?channelId=695&contentId=104685

代码仅从本地显式配置的输入读取，不自动下载、不搜索其他成绩表。数据来源、SHA-256 和处理日志留在被忽略的本地数据目录。
